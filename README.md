Я выполнил Второе задание связанное с преобразованием Фурье. Все нужные типы Фурье находятся в классе FastFFT, в нем функция fft сама решит массив какой кратности к нему пришел. Код не способен обрабатывать массивы НЕ кратные
2, 3 или 5. 
В самом коде лежит тест для него в функции main. Тест берет случайные значения с компьютера и собирает из них массив который впоследствии и будет обрабатываться кодом.
Все преобразования Фурье работают в соостветствии с Radix butterfly 2, 3 и 5 видов.
